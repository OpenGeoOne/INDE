# INDE Plugin for QGIS

## 🇧🇷 Plugin INDE para o QGIS

Este plugin permite adicionar e remover com facilidade conexões WMS, WFS, WCS e XYZ Tiles de instituições públicas brasileiras catalogadas na **INDE** – Infraestrutura Nacional de Dados Espaciais, coordenada pelo Ministério do Planejamento e pelo IBGE.

Com apenas um clique, é possível carregar dezenas de geoserviços oficiais diretamente no QGIS, otimizando o acesso a bases cartográficas públicas de alta qualidade.

Este projeto é mantido pela **GeoOne®**, uma iniciativa educacional que promove o uso de software livre para mapeamento e geotecnologias, capacitando profissionais e estudantes em todo o Brasil.

## 🇺🇸 INDE Plugin for QGIS

This plugin allows you to easily add and remove WMS, WFS, WCS, and XYZ Tiles connections from Brazilian public institutions cataloged in **INDE** — the National Spatial Data Infrastructure, coordinated by the Ministry of Planning and the Brazilian Institute of Geography and Statistics (IBGE).

With a single click, users can load dozens of official geoservices directly into QGIS, simplifying access to high-quality public mapping resources.

This project is maintained by **GeoOne®**, an educational initiative that promotes the use of open-source tools for mapping and geospatial technologies, empowering professionals and students throughout Brazil.
